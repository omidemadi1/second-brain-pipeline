# TypeUI Design Extractor - Chrome Extension

## Summary
Chrome extension (30k installs, 5 stars) that converts any website's design into SKILL/DESIGN.md prompts for AI replication.

## Features
- Extracts design patterns from websites
- Generates SKILL/DESIGN.md prompts
- Works with Claude, Cursor, OpenCode, Windsurf, etc.

## Use Cases
- Replicate website designs with AI
- Generate design specifications
- Create design tokens from live sites

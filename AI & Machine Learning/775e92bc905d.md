# Taste Skill — Anti-Slop Frontend Framework (Web)

## Summary
Guide file for AI coding tools that improves UI design quality. Teaches AI to avoid cliché designs (purple gradients, glass cards). Covers fonts, spacing, colors, animations, brand alignment. Works with Cursor, Claude Code, Codex, Windsurf, v0.

## Install
```bash
npx skills add Leonxlnx/taste-skill
```

## Key Features
- Brief inference — reads the room before generating
- Design system mapping
- Dark mode protocol
- Redesign protocol (audit-first)
- Block library schema
- Hard pre-flight check

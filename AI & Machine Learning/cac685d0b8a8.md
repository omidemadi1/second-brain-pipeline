## AI & Machine Learning

**Microsoft Skill Recorder** — Open-source Electron app from Microsoft.

**How it works:**
1. Record an on-screen work session locally (windows, URLs, clicks, optional narration)
2. Analyze sends timeline + frames to GitHub Copilot CLI
3. Copilot reconstructs intent + ordered steps
4. Export as **Skill** (SKILL.md) or **Automation** (scheduled/triggered)
5. Targets: Microsoft Scout, Copilot Cowork, Copilot Studio

**Key difference:** Not a macro recorder. It prefers native agent tools (gh, web_fetch) over brittle UI clicks. Generalizes from one example.

Install from pinned release on macOS or Windows.

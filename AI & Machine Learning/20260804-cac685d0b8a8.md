# Microsoft Skill Recorder

## Summary
Open-source Electron app from Microsoft that records screen to learn how you perform a task, then converts it into a skill/prompt for AI agents to repeat.

## How It Works
1. Install from pinned release (macOS/Windows)
2. Grant screen recording permission
3. Hit record and do the task once
4. Optionally narrate while working
5. Stop and review reconstructed steps
6. Edit anything that's off
7. Create a Skill or Automation

## Key Features
- Local capture (privacy-first)
- Copilot analysis on demand
- Exports prefer real tools (gh, web_fetch) over click scripts
- Generates SKILL.md files
- Supports scheduled Automations

## Target Platforms
- Microsoft Scout
- Copilot Cowork
- Copilot Studio

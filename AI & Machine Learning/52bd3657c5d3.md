# OpenSpec — Spec-Driven Development Framework

## Summary
Open-source Spec-Driven Development tool. Before writing code, generates change proposals, design decisions, and task lists as spec files in repo. Works with Claude Code, Cursor, Windsurf, Copilot, Gemini CLI. No API key or MCP needed.

## Features
- Review intent, not just code — each change produces a spec delta
- Context that persists — specs live in the repository alongside code
- Something to review in seconds — proposal, tasks, design decisions generated before code
- Brownfield-first approach for mature codebases
- Lightweight and minimal process

## How It Works
```bash
agent > /openspec:proposal Add remember me checkbox with 30-day sessions
```
Generates:
- `proposal.md` — describe the change
- `design.md` — technical decisions
- `tasks.md` — implementation tasks
- `specs/` — spec deltas

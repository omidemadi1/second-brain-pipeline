## AI & Machine Learning

**Lapse** — Personal memory layer for AI assistants.

**Features:**
- Auto-saves important conversations from Claude/ChatGPT/Codex via MCP
- Tags and dates entries
- Any agent can read your memory
- Email signup (no password), iPhone Action Button support
- Privacy-first with consent

**How it works:**
1. Connect an AI agent
2. Say "log this: ..." in any chat
3. Entries are stored with tags and dates
4. Your context: one shared memory all your AIs catch up on
5. Spaces: personal vs shared (personal stays private by default)

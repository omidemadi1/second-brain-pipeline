### Simplest AI Agent Memory System — 4 Markdown Files, Zero Databases

**1. One file per domain (never per date)**
Create separate files: people.md, companies.md, deals.md, tasks.md. Domain separation means your agent pulls the one file it needs.

**2. MEMORY.md index that maps everything**
One file listing every memory file with a one-line description. Agent loads index first, pulls specific files on demand.

**3. Cache files with freshness headers**
Any file mirroring an external source is a cache. Mark with `last_sync` timestamp. Train agent to announce data freshness before analysis.

**4. Flat markdown, not databases**
Markdown > vector DB for personal agents: readable, searchable, git-trackable. Skip embedding pipeline, retrieval infrastructure, abstraction layers.

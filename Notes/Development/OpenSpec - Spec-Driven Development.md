## Summary

OpenSpec is an open-source spec-driven framework for coding agents and CLIs. Before writing code, it generates change proposals, design decisions, task breakdowns, and spec deltas as files in your repo. Works with Claude Code, Cursor, Windsurf, Copilot, Gemini CLI — no API key or MCP needed. Specs live alongside code, organized by capability. When agents need context about how a feature works, they read the spec. Plans persist across chat sessions. Great for brownfield projects where understanding the current system is the struggle.

## Key Takeaways

- Spec-driven: plan before code, review intent not just code
- Specs persist in the repo — context survives session boundaries
- Change proposals + design decisions + task lists generated automatically
- Works with all major AI coding tools, no API key needed
- Ideal for brownfield projects with complex existing codebases
- Lightweight with minimal process overhead

## Summary

freeCodeCamp released a comprehensive course (April 2026) teaching how to build an interactive 3D "Cozy Cafe" portfolio from scratch using **Blender** for 3D modeling and **Three.js** for web rendering. Taught by Andrew Woan, the course covers the full professional workflow: subdivision modeling and clean topology in Blender, texture painting, TSL (Three.js Shader Language) shaders, singleton architecture for clean code organization, mobile-responsive raycasting for interaction, scroll-based animations, and even AI-assisted Blender scripting. The end-to-end approach is the key differentiator — most 3D tutorials stop at one tool, but this teaches where bottlenecks really are (modeling, interaction, or performance). Available free on YouTube and as a written tutorial on freeCodeCamp.org.

## Key Takeaways

- **Full-stack 3D workflow** — Blender modeling → Three.js rendering → interaction → performance optimization
- **Professional techniques**: subdivision modeling, texture painting, TSL shaders, singleton pattern
- **Interaction focus**: raycasting, scroll-driven animations, mobile-responsive

## Summary

**Repowise** is an open-source codebase intelligence tool that pre-analyzes and documents your entire project before AI coding agents touch it. Instead of the model reading files one by one, it starts with a comprehensive overview of the project structure. Claims up to **98% token reduction** depending on project size and structure.

Key features:
- **Auto-documentation** of files and project structure
- **Dependency graph generation** — visualizes how components connect
- **Git history analysis** — identifies weak points and patterns in the codebase
- **Dead code detection** — finds unused code and outdated dependencies
- **Compatible with**: Claude Code, Cursor, GitHub Copilot
- **MCP integration** — works as an MCP server
- Open-source, Python, 4,988 GitHub stars

# ScrapeGraphAI — AI-Powered Web Scraping Library

## Summary

ScrapeGraphAI is an open-source Python library (30K+ GitHub stars) that uses LLMs to scrape web content using natural language descriptions. Instead of writing CSS selectors or XPaths, you describe what data you want in plain English, and the library returns structured results. It uses a direct graph-based pipeline architecture with LLM-powered node selection to navigate pages and extract content. Supports multiple LLM backends (OpenAI, Claude, Gemini, local models) and handles JavaScript-rendered pages, making it useful for lead generation from LinkedIn, competitor ad tracking, research automation, and general web data extraction. Works with Claude Code and major AI coding agents. GitHub: https://github.com/ScrapeGraphAI/Scrapegraph-ai

## Key Takeaways

- **Natural language scraping**: Describe what you want in plain English — no CSS/XPath needed
- **30K+ GitHub stars**: Very popular and actively maintained open-source project
- **Multi-LLM support**: Works with OpenAI, Claude, Gemini, Ollama (local), and more
- **Pipeline architecture**: Uses graph-based logic to break scraping into navigable steps
- **Agent-compatible**: Works with Claude Code and other AI coding agents out of the box
- **Use cases**: Lead gen, competitor tracking, research, data collection from any website
- **Free and open source**: No paid API required for the core library (LLM costs still apply)

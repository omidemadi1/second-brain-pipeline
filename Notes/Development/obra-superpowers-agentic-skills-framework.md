# obra/superpowers — Agentic Skills Framework & SDLC Methodology

## Summary

**Superpowers** is an agentic skills framework and software development methodology that works. Created by Jesse (obra), it provides a structured approach to AI-assisted development using subagents. The repo has 277,125 stars — a massive community signal that this is a widely-adopted tool.

The framework is built on Shell and focuses on:
- **Agentic skills** — reusable skill definitions that AI agents can follow
- **Subagent-driven development** — breaking complex tasks into subtasks delegated to specialized agents
- **SDLC integration** — structured software development lifecycle with AI agents at each stage
- **Skills methodology** — a way to codify development patterns into agent-readable instructions

As described by a user (@DevTwitter | Dara): "Even though a large part of my token consumption goes to Superpowers, I can no longer work without it." This speaks to the framework's productivity impact despite its resource cost.

**Topics tagged:** ai, brainstorming, coding, obra, sdlc, skills, subagent-driven-development, superpowers

The framework represents a paradigm shift from "AI writes code" to "AI follows structured development processes" — making agent outputs more predictable and reliable.

## Key Takeaways

- 277K+ GitHub stars — one of the most popular AI development frameworks

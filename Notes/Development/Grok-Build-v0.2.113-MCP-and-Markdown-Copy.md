## Summary

Grok Build v0.2.113 ships two useful quality-of-life features:

1. **MCP server management from CLI** — Run `grok mcp enable` and `grok mcp disable` to toggle MCP (Model Context Protocol) servers directly from the command line, no config file editing required.
2. **Copy full markdown output in plan mode** — Press `y` in plan mode to copy the entire markdown output to your clipboard.

Source: @smartainewss

## Key Takeaways

- MCP servers can now be toggled on/off without leaving the terminal
- Plan mode outputs can be copied in full with a single keystroke
- Incremental but practical improvements to the Grok Build workflow

## My Notes

This is a quality-of-life update for Grok Build users. The MCP enable/disable CLI commands are a welcome addition for managing multiple tool integrations without manually editing configs. The markdown copy shortcut in plan mode is handy for documenting or sharing plans.

# AI Website Cloner Template — Multi-Agent Code Generation

## Summary
JCodesMore's ai-website-cloner-template (github.com/JCodesMore/ai-website-cloner-template) is an open-source project that takes a URL and recreates any website as a clean, production-ready Next.js + Tailwind CSS codebase using AI agents. The pipeline works in multiple phases: 1) Extract all design tokens, colors, fonts, spacing, and pixel-accurate values, 2) Take screenshots of every section to understand the visual structure, 3) Distribute the rebuild work across 10+ AI coding agents working in parallel, 4) Deliver clean, non-scraped code. It works best with Claude Code and has recently hit 30,000 GitHub stars — one of the biggest open-source AI coding projects of the year.

## Key Takeaways
- Takes a single URL → outputs a working Next.js + Tailwind codebase.
- Multi-agent approach: 10+ AI agents work simultaneously on different site sections.
- Best results with Claude Code, but uses AI coding agents broadly.
- Extracts design tokens, colors, fonts, spacing before writing code.
- 30K GitHub stars — extremely popular, battle-tested.
- Rebuilt sites are clean code, not scraped HTML.
- Available on SourceForge as a mirror.

## Summary

**What:** CodeWiki by Google is a tool that generates interactive documentation from GitHub repositories, including dependency graphs, module explanations, and beginner tutorials.

**Key features:**
- Paste a GitHub repo link — AI generates complete documentation
- Automatic dependency graphs showing code relationships
- Step-by-step module explanations
- Beginner-friendly tutorials for onboarding
- Built-in chatbot for asking questions about the codebase
- API reference and architecture overviews

**Use case:** Developers onboarding to new codebases, teams documenting existing projects, or anyone wanting to understand a repository without reading all the code.

> This eliminates the "where do I start?" problem for large codebases.

## Key Takeaways

- AI-generated documentation can dramatically reduce onboarding time
- Dependency graphs provide visual architecture understanding
- The chatbot feature allows interactive exploration of code concepts
- Works with any public GitHub repository
- Complements tools like Graphify for different documentation needs

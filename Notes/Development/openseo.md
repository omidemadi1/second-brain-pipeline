## Summary

OpenSEO is an open-source alternative to Semrush and Ahrefs, providing keyword research, SERP analysis, site auditing, competitor analysis, backlink analysis, and AI overview tracking. Written in TypeScript with nearly 8K GitHub stars, it supports MCP (Model Context Protocol) for AI agent integration and can be self-hosted via Docker. A free tier is available for hosted usage.

## Key Takeaways

- **Semrush/Ahrefs alternative**: Full-featured SEO toolset as open source — keyword research, SERP analysis, site audits, backlinks, and competitor analysis in one package
- **MCP integration**: Supports Model Context Protocol, meaning AI agents (including Hermes) can query SEO data programmatically — this bridges SEO and AI workflows
- **Self-hostable**: Docker deployment means full data control, no reliance on third-party SEO platforms, and potentially unlimited queries
- **AI overview tracking**: Tracks AI-generated search overviews (Google SGE/AI Overview), a cutting-edge feature as search evolves

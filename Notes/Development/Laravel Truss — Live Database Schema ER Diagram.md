# Laravel Truss — Live Database Schema ER Diagram

## Summary

**Laravel Truss** (⭐ 248) is a Laravel package that scans your database schema and renders it as a scrollable, zoomable ER diagram directly inside your application — no external tools needed.

### Key Features
- **Structure-only**: Reads tables, columns, keys, and indexes — never accesses actual data
- **Focus mode**: See a single table and its foreign key neighbors
- **Filter by table name** and switch between native types and Laravel labels
- **Offline-capable**: Works without CDN, fully local
- Built with Mermaid under the hood
- Language: PHP

### Why It's Useful
When working on projects with complex database schemas — especially when multiple developers are involved and the schema keeps evolving — manually tracing foreign keys in a DB client is tedious. Truss provides instant visual understanding of table relationships within the app itself.

Homepage: https://trussphp.com/

## My Notes

Not directly useful since we're not working on a Laravel project currently, but a good tool to bookmark for any future PHP/Laravel work. The "structure-only, never data" approach is a smart security pattern for schema visualization tools.

## Summary

SkillsGate is an open-source (MIT) desktop app + terminal tool for managing skills across 20+ coding agents including Claude Code, Cursor, Codex CLI, GitHub Copilot, and more. It provides a unified catalog search (skills.sh), per-agent install control, an internal editor for viewing/editing skill source, and remote management via SSH for team skill sharing. Solves the fragmentation of managing skills across multiple AI coding assistants.

## Key Takeaways

- **20+ agents supported** — Claude Code, Cursor, Codex CLI, Copilot, etc.
- **Unified catalog** — Direct search of skills.sh without manual file copying
- **Per-agent control** — Install on specific agents or all at once
- **Built-in editor** — View/edit skill source, save to disk directly
- **Remote management** — SSH support for managing remote machines
- **Team sharing** — Share skill configurations across team
- **MIT licensed** — Fully open source

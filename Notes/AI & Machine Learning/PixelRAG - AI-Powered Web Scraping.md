## Summary

PixelRAG is an AI-powered web scraping tool that crawls websites, takes screenshots of each page, and uses LLMs/VLMs to understand site structure. Instead of parsing HTML, it "sees" pages visually like a human would. Scalable pixel-native search. 9k stars. The end of traditional web parsing — beginning of visual understanding.

## Key Takeaways

- Screenshots-based web understanding, not HTML parsing
- Uses VLMs to interpret visual page structure
- Scalable pixel-native search
- 9k stars, Python
- Published paper on arXiv
- Different approach to traditional RAG pipelines

## My Notes

Interesting approach for scraping visually complex websites. The screenshot-based method bypasses anti-scraping measures that target HTML crawlers. Could be useful for fashion e-commerce scraping.

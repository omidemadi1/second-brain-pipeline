# Grockbot — AI Agent Team Platform Tutorial

## Summary

Grockbot is an AI agent platform that lets you create a team of AI agents that can sign into real tools, use them, and take action on your behalf — no technical skills required. The interface is Telegram-style, agents can talk to each other, delegate work, and operate autonomously (even while you sleep). Nate walks through a full setup from scratch, demonstrating how to build an executive team (EA, COO, CCO, CFO) that collaborates in group channels, discusses strategy, and produces actionable plans. The platform supports four tiers: Free (1 agent), Pro ($30/mo, 3 agents), Business ($50/mo, 10 agents), and Enterprise ($200/mo, unlimited). Key capabilities include: agents with real tool access (Google Drive, Gmail, Slack, etc.), multi-agent collaboration and delegation, autonomous scheduled tasks, custom skills/training, and voice input. Use cases covered include: sales outreach automation (lead research + cold email via Clay/Gmail), content repurposing pipelines, customer support, operations management, and business strategy. Nate also outlines a business model for selling Grockbot setup as a service: free audit → training → retainer, with the platform itself being the differentiator vs. hiring humans.

## Key Takeaways

- **Agents as real teammates**: Unlike chatbots, Grockbot agents can sign into tools (Google, Slack, etc.), read/write data, and execute multi-step workflows autonomously.
- **Multi-agent collaboration**: Agents talk to each other in group channels, tag each other, delegate tasks, and produce joint outputs — like a real leadership team.
- **No-code setup**: Built for non-technical users. Agents are configured via chat instructions, not code.
- **Business opportunity**: Selling Grockbot setup to other businesses is a viable service offering — start with free audits, build trust, then upsell retainers.
- **Pricing**: Free tier (1 agent) → Pro $30/mo (3) → Business $50/mo (10) → Enterprise $200/mo (unlimited).
- **Custom skills**: You can train agents on specific tools and workflows, then save these as reusable skill templates.
- **Voice interaction**: Supports voice input for hands-free agent communication.
- **Sales automation example**: Lead research agent → outreach writer agent → scheduling agent (via Clay/Gmail), with a daily optimization agent improving copy and workflows.
- **Differentiator vs. hiring**: Cheaper than full-time hires, faster to onboard, works 24/7, no turnover risk — but still needs human oversight for strategy.
- **Skill marketplace**: Users can publish and share agent skill templates across the platform.

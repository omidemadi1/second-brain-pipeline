# Why Most AI Demos Fail in Production

**Source:** Personal note (ByteByteGo infographic)

## Summary

ByteByteGo infographic detailing 8 failure modes when AI demos hit production: messy data, retrieval failures, outdated evals, missing monitoring, token cost scaling, data drift, prompt coupling, and cascading failures.

## Key Takeaways

- Clean demo data vs messy production data is a major gap
- Retrieval failures cause hallucinations in production
- Outdated evals create false confidence in model quality
- Standard monitoring misses AI-specific failures
- Token costs compound at scale unexpectedly
- Data drift causes silent regressions
- Prompt coupling creates deployment risks
- Cascading pipeline failures are hard to debug

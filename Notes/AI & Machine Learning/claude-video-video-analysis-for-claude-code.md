## Summary
Open-source video analysis tool designed for Claude Code. Summarizes videos and extracts key points with timestamps. Supports YouTube, TikTok, Loom, local files, and screen recordings. Processes only key frames for significant cost reduction. Uses Groq Whisper for fast speech-to-text transcription.

## Key Takeaways
- Processes only key frames instead of every frame, delivering significant cost reduction for video analysis
- Supports multiple video sources: YouTube, TikTok, Loom, local files, and screen recordings
- Uses Groq Whisper for fast speech-to-text transcription, enabling efficient video summarization

## Summary

**What:** A community-discovered method to obtain free API access to Qwen models via a proxy endpoint and connect them to Hermes or other AI harnesses.

**Key details:**
- API Base URL: `https://qwen.aikit.club/v1` (OpenAI-compatible)
- API key extracted from browser cookies after logging into Qwen
- Works with Hermes and other OpenAI-compatible harnesses
- Author notes account suspension risk was lower than expected — no issues after 24+ hours

> ⚠️ This is an unofficial workaround — not an officially supported API endpoint. Use at your own risk.

## Key Takeaways

- Qwen provides a free API tier that can be accessed through a proxy endpoint
- The API is OpenAI-compatible, making it easy to integrate with existing tools
- Author compared this to a similar DeepSeek workaround that resulted in 48-hour account suspension
- After 24+ hours of testing, the Qwen account remained active
- Step-by-step setup instructions were provided in follow-up tweets

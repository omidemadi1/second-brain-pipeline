## Summary

OpenWiki is an open-source CLI tool by LangChain that automatically generates and maintains documentation for agent codebases. It solves the chronic problem of documentation drift — where docs become stale after code changes. OpenWiki continuously scans the codebase, understands agent logic, and keeps docs in sync. It also builds a "personal memory" from diverse sources, creating a RAG-ready knowledge base for agents. 15K+ stars on GitHub, built in TypeScript.

## Key Takeaways

- **Auto-generates & maintains docs** — no manual updates after code changes
- **Agent-native** — designed specifically for AI agent codebases
- **Personal memory layer** — ingests diverse sources into queryable knowledge
- **RAG-ready** — outputs structured data for retrieval-augmented generation
- **15K+ stars** — strong community adoption
- **TypeScript** — type-safe, extensible

# Grok Build CLI v0.2.112 Features

**Source:** Personal note (via @smartainewss)

## Summary

Grok Build CLI v0.2.112 adds /tutorial command, tool_overrides for search limits, /doctor improvements, queued prompt editing, voice shortcut toggle, and hooks in config.toml.

## Key Takeaways

- New /tutorial command for onboarding
- tool_overrides for search date/domain limits
- /doctor improvements for diagnostics
- [edit] button for queued prompts
- Voice shortcut toggle
- Workflow progress and retry capabilities
- Hooks now configurable in config.toml

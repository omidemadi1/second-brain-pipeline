## Summary

Bina 0.1 is a Persian/Farsi OCR model hosted on HuggingFace. It's a BF16 merged release of a Persian OCR LoRA checkpoint (step 8,000) from the surya-ocr-2-persian-lora-7m training, based on datalab-to/surya-ocr-2. Also available as Bina-0.1-Koochik-CoreML for Apple Silicon (2.95 GB). This is the immutable BF16 transcription baseline for Persian text recognition. Quantized derivatives should be compared against this model.

## Key Takeaways

- Persian/Farsi OCR using LoRA fine-tuning on surya-ocr-2
- BF16 and CoreML (Apple Silicon) variants available
- 2.95 GB CoreML model for local inference
- Immutable baseline for comparing other Persian OCR models
- Part of the growing Iranian AI ecosystem on HuggingFace

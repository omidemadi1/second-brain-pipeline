## Summary

Microsoft Skill Recorder is an open-source Electron app that records your screen to learn how you perform a task, then converts it into a SKILL.md or scheduled automation for AI agents. You record a work session — windows, URLs, clicks, optional narration. GitHub Copilot CLI analyzes the timeline and frames to reconstruct one intent plus ordered steps. The tool prefers native agent tools (gh, web_fetch) over replaying brittle UI clicks. Not a macro recorder — it generalizes from one example.

## Key Takeaways

- Records screen sessions to generate AI skills automatically
- Uses Copilot CLI to reconstruct intent and ordered steps
- Generates SKILL.md or scheduled automations
- Prefers real tools over brittle click scripts
- Generalizes from one demonstration
- Open-source Electron app from Microsoft
- Available on macOS and Windows

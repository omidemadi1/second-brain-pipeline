# awesome-gpt-image-2 — Prompt as Code Engine

## Summary

awesome-gpt-image-2 (26K+ stars) is an industrial-grade Prompt as Code library for GPT-Image2 and OpenAI's image/video generation API. It reverse-engineers 530+ community prompt patterns into reusable, code-based templates — treating prompts as structured code rather than freeform text. The library provides 20+ industrial-grade template sets covering image generation, batch processing, and automated workflows. It abstracts complex prompt chains into composable skills installable via `npx skills add`, and supports both image and video generation through a single async API (submit task → get ID → poll for results). Homepage: https://gpt-image2.canghe.ai — written in JavaScript, topics include agents, workflow-automation, and prompt-engineering.

## Key Takeaways

- **530+ reverse-engineered prompt cases**: Real community patterns distilled into reusable templates
- **20+ industrial template sets**: Pre-built prompt structures for common generation tasks
- **Prompt as Code**: Treats prompts like code — structured, versionable, composable
- **Skills system**: Install prompt skills via `npx skills add freestylefly/awesome-gpt-image-2 --global --all --copy`
- **Single async API for image + video**: One pipeline handles both media types
- **Agent-friendly**: Designed to work with AI coding agents (Claude Code, OpenCode, etc.)
- **26K+ GitHub stars**: Strong community adoption and active maintenance

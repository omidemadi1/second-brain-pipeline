## Summary

**What:** Keenable is a free web search and page-to-markdown extraction service built specifically for AI agents, providing low-latency search via CLI, REST API, and MCP server.

**Key features:**
- Free web search + page reading + extraction for agents
- Works with OpenClaw, Hermes, and other agent frameworks
- CLI, REST API, and MCP server interfaces
- Page-to-markdown conversion for clean content extraction
- Email signup, no credit card required
- Low-latency designed for real-time agent workflows

**Use case:** AI agent developers who need affordable, reliable web search capabilities for their agents without paying for expensive search APIs.

> A compelling free alternative to paid search APIs for agent development.

## Key Takeaways

- Free tier makes it accessible for experimentation and personal projects
- MCP server integration means it works with existing agent setups
- Page-to-markdown conversion is essential for clean content processing
- The Hermes plugin exists as a standalone package (hermes-keenable-web)
- Designed specifically for agent use cases, not general web search

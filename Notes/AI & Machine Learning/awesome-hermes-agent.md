## Summary

Awesome Hermes Agent is a curated directory of skills, plugins, memory providers, tools, surfaces, and guides for Nous Research's open-source Hermes Agent. The list categorizes resources into ready-made, experimental, and beta tiers, covering the growing ecosystem around Hermes. With over 5,000 stars, it serves as the primary discovery point for anyone building on or extending Hermes Agent.

## Key Takeaways

- **Ecosystem breadth**: Hermes has a surprisingly large ecosystem with ready-made skills, experimental plugins, memory providers, MCP integrations, and community guides
- **Categorization tiers**: Items are sorted into ready-made (production-ready), experimental (working but unproven), and beta (in development) — useful for evaluating reliability before adopting
- **MCP integration**: Several tools support Model Context Protocol, indicating Hermes is positioning as a composable AI agent platform alongside the broader MCP ecosystem

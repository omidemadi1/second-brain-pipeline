# TypeUI — Chrome Extension for Design Extraction

## Summary
- **TypeUI** is a **Chrome extension** (30k installs, 5-star rating) that extracts a website's design style into **SKILL/DESIGN.md prompts** for AI replication.
- Compatible with **Claude**, **Cursor**, **Windsurf**, **OpenCode**, and other AI tools.
- Enables **design extraction** and **AI-assisted design replication** for web developers and designers.
- **Beginner-friendly** and practical for **web design** and **UI/UX** workflows.

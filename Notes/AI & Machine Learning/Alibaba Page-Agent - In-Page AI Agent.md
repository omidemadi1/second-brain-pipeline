## Summary

Alibaba Page-Agent is an open-source AI agent embedded directly in web pages. Unlike browser automation tools that use screenshots/computer vision, it works with the DOM directly. Simple script deployment. 28k stars. Controls web interfaces using natural language via JavaScript injection. The DOM-direct approach is more reliable and efficient than screenshot-based approaches.

## Key Takeaways

- AI agent embedded directly in web pages
- Works with DOM directly, not screenshots
- Simple script deployment
- 28k stars, TypeScript, by Alibaba
- Natural language control of web interfaces
- MCP support for agent communication

## My Notes

Different approach to browser automation — DOM-direct vs screenshot-based. More reliable for structured web pages. Could be useful for automating web tasks within specific sites.

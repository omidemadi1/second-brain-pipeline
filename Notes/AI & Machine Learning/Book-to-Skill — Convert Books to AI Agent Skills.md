# Book-to-Skill — Convert Books to AI Agent Skills

## Summary

Book-to-Skill is a tool that converts any book (PDF/EPUB/DOCX/Markdown) into an AI agent skill. It automatically extracts chapter summaries and key points, reducing token consumption by up to 51x. The GitHub project at github.com/virgiliojr94/book-to-skill provides the conversion pipeline. This is highly relevant to Hermes — you could convert reference books into skills that agents can load on demand, getting the knowledge without burning massive context windows. Particularly useful for technical books you want to reference but can't afford to feed entirely into an LLM.

## Key Takeaways

- Converts PDF, EPUB, DOCX, and Markdown books into AI agent skills
- Automatic chapter summarization and key point extraction
- Reduces token consumption by up to 51x
- Open source GitHub project
- Compatible with agent skill frameworks (like Hermes)
- Enables "load on demand" knowledge without full context injection

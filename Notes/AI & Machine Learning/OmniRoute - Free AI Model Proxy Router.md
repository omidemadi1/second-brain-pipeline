## Summary

OmniRoute is a free MIT-licensed AI gateway providing a single endpoint to access 290+ providers (90+ free) and 500+ models including Kimi, Claude, GPT, Gemini, DeepSeek, MiniMax. Key features include quota-aware auto-fallback, RTK+Caveman compression saving 15-95% tokens, MCP/A2A protocol support, and a desktop/PWA app that runs on Termux for phone use. Compatible with Claude Code, Codex, Cursor, OpenCode, Cline, and Copilot. Built by 500+ contributors with 42k+ GitHub stars. More powerful than 9Router but uses more resources — an alternative to consider if the VPS can handle it.

## Key Takeaways

- 290+ providers, 90+ free — massive cost reduction potential
- Token savings of 15-95% via RTK+Caveman compression
- Quota-aware auto-fallback prevents service interruption
- Works with all major coding agents (Claude Code, Cursor, Codex, etc.)
- Can run on Termux (phone) — extreme portability
- MIT licensed, community-driven with 42k+ stars
- More resource-heavy than 9Router — may not suit a 3.7GiB RAM VPS

## My Notes

Interesting alternative to 9Router for the Hermes setup. The token compression feature could save significant costs. However, higher resource usage may be problematic on the current VPS. Worth testing in a low-memory configuration.

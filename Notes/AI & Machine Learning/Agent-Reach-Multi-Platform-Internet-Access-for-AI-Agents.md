## Summary
Give your AI agent eyes to see the entire internet. Agent-Reach provides read & search access to Twitter/X, Reddit, YouTube, GitHub, LinkedIn, Bilibili, XiaoHongShu and more — one CLI, zero API fees. 63k+ GitHub stars, Python-based. Install via `pip install agent-reach`, run `agent-reach install`, and the agent can use upstream platform tools directly.

## Key Takeaways
- One CLI gives access to 8+ major platforms (Twitter, Reddit, YouTube, GitHub, LinkedIn, Bilibili, XiaoHongShu)
- Zero API fees — uses open-source backends, no paid API keys required
- 63k+ GitHub stars, actively maintained, Python-based
- Works with Claude Code, Cursor, Hermes, and any AI agent that can run shell commands
- One-command install: `pip install agent-reach && agent-reach install`

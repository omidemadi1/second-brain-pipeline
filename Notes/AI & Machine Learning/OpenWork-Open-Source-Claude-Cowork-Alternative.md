## Summary

**What:** OpenWork is an open-source alternative to Claude Cowork, built on OpenCode with free model access, enabling task automation and team shared workspaces for AI agents.

**Key features:**
- Bring your own model and provider
- Reusable agent setups across organizations with guardrails
- Works with Claude Code, Cursor, Codex, OpenCode, and other agents
- Shared skills and MCPs across team workspaces
- Browser automation, data analysis, outreach, and content creation
- Y Combinator backed

**Use case:** Teams that want to deploy AI agents with shared configurations, skills, and workflows across their organization.

> This is enterprise-grade agent orchestration with open-source flexibility.

## Key Takeaways

- Bridges the gap between individual AI agent use and team collaboration
- Skills and MCPs can be shared once and used by the entire organization
- Works as an MCP server — integrates with existing agent setups
- The "paste a prompt to install" approach lowers adoption friction
- Supports multiple agent clients (Claude Code, Cursor, Codex, ChatGPT, etc.)

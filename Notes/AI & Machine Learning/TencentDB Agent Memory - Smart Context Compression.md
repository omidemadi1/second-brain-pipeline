## Summary

TencentDB Agent Memory is a team-level memory hub for AI agents, reducing token usage up to 61%. It auto-summarizes long conversations while preserving tasks, facts, docs, and code in four reusable memory assets: Chat Memory, Skill, LLM-Wiki, and Code-Graph. These are governed, shared, and equipped across agents and frameworks. Maintains agent identity in long sessions. Open-source, runs locally with vector search. 17.5k stars.

## Key Takeaways

- Reduces token usage up to 61% — significant cost savings
- Four memory types: Chat Memory, Skill, LLM-Wiki, Code-Graph
- Maintains agent identity across long sessions
- Local-first with vector search
- Team-level memory sharing across agents
- 17.5k stars, TypeScript-based

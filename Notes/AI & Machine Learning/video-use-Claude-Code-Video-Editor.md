## Summary

**video-use** is an open-source tool from the **browser-use** team that turns **Claude Code** into a fully functional AI video editor. You drop raw footage into a folder, describe what you want in natural language (chat with Claude Code), and get a polished `final.mp4` back — no timeline UI, no manual editing, no presets. It works for any content type: talking heads, montages, tutorials, travel videos, interviews. The workflow: transcribes footage → reasons about cuts from transcript → proposes strategy in plain English → waits for confirmation → executes with ffmpeg. Also available via Browser Use Cloud for hosted usage. 100% open source.

## Key Takeaways

- **Chat-based video editing** — natural language describes edits, no timeline UI
- **Transcript-driven** — analyzes speech/content to propose intelligent cuts
- **Human-in-the-loop** — proposes strategy, waits for confirmation before executing
- **ffmpeg backend** — professional-grade output, no quality loss
- **Works for any content** — talking heads, montages, tutorials, travel, interviews
- **Open source + hosted option** (Browser Use Cloud)
- **From browser-use team** — proven agent infrastructure

## My Notes

This is a game-changer for developers who need video editing but don't want to learn Premiere/DaVinci. The transcript-based approach is smart — it understands content semantically, not just visually. Could be extremely useful for the wardrobe styling app: auto-generating product showcase videos, tutorial content, social media clips from raw footage. The "propose then confirm" workflow prevents costly mistakes. Since it's Claude Code native, it fits perfectly into existing AI-assisted workflows. Worth trying on a small project first.

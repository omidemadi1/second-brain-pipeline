## Summary

**Grok Bot** is xAI's always-on AI agent platform (launched August 2026) that runs a fleet of specialized agents synced across Windows, Mac, and iOS — each with its own persistent computer and browser session. The standout feature is **"Teach a Task" mode**: record a Chrome browser session to teach the agent a new workflow, which it then replicates autonomously. Grok 4.6 (released Aug 12, 2026) focuses on long-running agents with API pricing at $2/M input / $6/M output tokens. Grok Bot isn't sold separately — it rides on existing Grok or Cursor plans (per x.ai/bot). Agents maintain persistent state across sessions, enabling 24/7 automated work. Setup guides cover MCP (Model Context Protocol) integration, automation workflows, and plugin ecosystems. Rahul (@sairahul1) describes it as "an army of agents that can do work for you 24/7" with "super powers" when configured correctly.

## Key Takeaways

- **Persistent agent fleet** — Each agent has its own persistent computer + browser session across devices
- **Teach a Task mode** — Record browser workflows once, agents replay them autonomously
- **Cross-platform sync** — Windows, Mac, iOS with shared agent state
- **Grok 4.6 optimized** — Built for long-running agents (Aug 12, 2026 release)
- **Subscription model** — Included with Grok/Cursor plans, not standalone ($2/$6 per M tokens API)
- **MCP support** — Model Context Protocol integration for tool/extension ecosystem
- **24/7 automation** — Agents run continuously, not just chat sessions
- **Plugin ecosystem** — Extensible with plugins for specialized tasks

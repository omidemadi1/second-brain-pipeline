## Summary

Ori Eval by OpenRouter is an AI model evaluation tool that runs your agent on real prompts, checks tool calls, and scores outputs to find the best model for your specific project. Compares models like Claude Opus 5, GPT-5.6, Gemini 3 Pro. Unlike generic benchmarks, Ori Eval tests models on YOUR actual use case and tool interactions, giving you a personalized quality score.

## Key Takeaways

- Run your agent on real prompts to evaluate model performance
- Checks tool call correctness, not just text output
- Compares frontier models (Opus 5, GPT-5.6, Gemini 3 Pro)
- Personalized evaluation — your prompts, your tools
- By OpenRouter — integrated with their platform

## Summary

**What:** A practical guide on connecting OpenCode to Qwen's free API endpoint, including configuration setup and token extraction.

**Key details:**
- Qwen API Base URL: `https://qwen.aikit.club/v1` (OpenAI-compatible)
- API key extracted from browser cookies after Qwen login
- OpenCode configuration shared via GitHub Gist
- Based on the same Qwen free API method shared by @bookunt
- Users only need to add their own token to the provided config

**Use case:** Developers using OpenCode who want to access Qwen models without paid API subscriptions.

> This builds on the Qwen free API workaround, providing a concrete setup for OpenCode users.

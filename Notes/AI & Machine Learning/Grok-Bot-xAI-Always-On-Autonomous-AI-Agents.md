# Grok Bot - xAI Always-On Autonomous AI Agents

## Summary

xAI launched Grok Bot on August 11, 2026 — a major shift from chatbots to persistent, always-on AI agents. Each Grok Bot gets its own virtual cloud computer with independent logins, can browse the web like a human, stay signed into services, and run tasks autonomously even while you sleep. The agents can respond to messages in Slack and GitHub, manage inboxes, update CRMs (Notion, Linear, Slack), research people and companies, write drafts in your voice, learn workflows after observing once, convert them into repeatable skills, coordinate with other agents, open GitHub PRs, generate files sent directly to chat, prepare morning briefings from calendars, monitor items and send alerts, and continuously learn your work patterns. It hands off only for login and 2FA steps, then resumes autonomous operation. This marks xAI's entry into the "digital colleague" category — always-on agents with their own cloud computers rather than reactive chat interfaces.

## Key Takeaways

- Grok Bot agents each get their own cloud computer with persistent logins
- Handoff only required for login/2FA — everything else is autonomous
- Can interact with Slack, GitHub, CRM, email, Notion, Linear natively
- Learns workflows from a single observation and converts them to permanent skills
- Multi-agent coordination — agents can collaborate and handle parallel tasks
- Morning briefings, monitoring/alerts, and inbox management built in
- Launched August 11, 2026 — xAI's first always-on agent product

## My Notes

Relevant to our [[Hermes Agent]] setup — we already run always-on agents (Hermes cron jobs, background processes). Grok Bot's approach of giving each agent its own cloud computer is an interesting architectural pattern worth watching.

The "learn from one observation and convert to skill" capability is exactly what Hermes skills do. The difference is Grok Bot is hosted/sandboxed by xAI vs our self-hosted approach.

Worth monitoring whether this becomes a serious competitor to self-hosted agent stacks or remains a walled garden.

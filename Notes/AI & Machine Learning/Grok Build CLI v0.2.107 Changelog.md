# Grok Build CLI v0.2.107 Changelog

**Source:** [https://x.com/GrokInsider/status/2079302123620045092](https://x.com/GrokInsider/status/2079302123620045092)

## Summary

Grok Build CLI v0.2.107 adds stop hooks with feedback loops, S3 session resume, rotating auth tokens, and auto-mode improvements. Significant upgrade for AI agent workflows.

## Key Takeaways

- Stop hooks can now keep the agent running by feeding feedback back to the model instead of ending the turn
- Sessions can now resume across hosts by mirroring transcripts to external storage like S3
- Custom models can authenticate using rotating tokens fetched from a command
- Auto mode now continues after classifier blocks by telling the agent the reason
- Recap summaries after idle now load much faster by reusing cached context

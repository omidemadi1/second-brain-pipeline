## Summary

Lapse is a personal memory layer for AI assistants. It auto-saves important conversations from Claude, ChatGPT, and Codex via MCP. Entries are tagged and dated. Any agent can read your memory. Email signup (no password), iPhone Action Button support, privacy-first with consent. Semantic search runs fully on-device with a small ~7MB model. Cross-agent memory sharing means a new client feels like the old buddy. Off by default — nothing exposed until you turn it on.

## Key Takeaways

- Personal memory layer for AI assistants via MCP
- Auto-saves conversations from Claude, ChatGPT, Codex
- Privacy-first: consent-based, off by default
- On-device semantic search (~7MB model)
- Tag and date entries for organization
- iPhone Action Button integration
- Cross-agent memory sharing

## My Notes

Interesting approach to AI memory that's different from Hermes's memory system. The consent-based, privacy-first design is appealing. The MCP integration is modern and standards-based.

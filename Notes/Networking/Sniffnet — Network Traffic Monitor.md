# Sniffnet — Network Traffic Monitor (Rust/iced)

## Summary

Sniffnet is a beautifully designed, open-source network traffic monitor built in Rust with the iced GUI framework. It identifies 6000+ services, protocols, trojans, and worms in real-time. Features include traffic filtering, connection inspection, host identification, service detection, PCAP export/import, IP blacklisting, and geographic location of remote hosts via MaxMind. Available on Windows, Mac, and Linux (AppImage). Dual-licensed MIT/Apache-2.0. Excellent for monitoring network traffic without deep packet inspection expertise — useful for auditing CCTV/IP camera network traffic flows.

## Key Takeaways

- Identifies 6000+ services, protocols, trojans, and worms
- Built in Rust with iced GUI — fast and beautiful
- Real-time traffic analysis with geographic mapping
- PCAP import/export for detailed analysis
- IP blacklisting and custom alert notifications
- Cross-platform: Windows, Mac, Linux (AppImage)
- Available in 26 languages
- Security-audited for user data privacy

## Summary
QR code based file transfer between phones. Converts files into rapid QR codes, second phone reads via camera and reassembles. No network needed — completely offline peer-to-peer transfer. 1289 stars, TypeScript-based.

- Transfer files between devices using only QR codes — no WiFi, no Bluetooth, no internet
- Converts files to rapid QR code sequences, camera reads and reassembles
- 1289 stars, TypeScript-based

## Summary

Stackyard is a self-hosted homelab dashboard that shows system status, disk health, backups, network speed, GitHub stats, libraries, and services. Add any API data as widget/badge without coding. Single container deployment, zero dependencies. Calm, live activity badges from any API. 3 stars — very new project.

## Key Takeaways

- Single container, zero dependencies deployment
- Add API data as widgets without coding
- Shows: system status, disk health, backups, network speed
- PWA support
- Very new (3 stars) — early stage

## My Notes

Simple alternative to more complex homelab dashboards like Homepage or Homarr. The zero-dependency, single-container approach is appealing for the VPS setup.

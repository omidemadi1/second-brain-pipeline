## Summary

**Hermes Bot Mode** (shipped by Nous Research, Aug 2026) transforms agent profiles into named **Bots** — each with its own role, model, memory, skills, tools, and profile picture. Bots can communicate and send work to each other, enabling a **specialist marketing team** inside Hermes Desktop. Shann³ (@shannholmberg, founder @espressioai, @lunarstrategy) outlines a 7-bot marketing team architecture with a shared **"Company Brain"** context layer. The Company Brain pulls in: transcripts/meeting notes, client threads, past campaigns, learnings/SOPs, workflows, offers/pricing, brand/voice rules, and examples of "what good looks like." A Research Bot fetches external context (competitors, channels, trends). The 7 specialist bots: **Research Bot** (external intel), **SEO Bot** (keywords, briefs, AEO for ChatGPT/Claude/Perplexity), **Content Bot** (trend research, drafting in brand voice, editor pass with anti-slop checks), **PR Bot** (story angles, media database, placement tracking), **Paid Bot** (ad angles, creative, bid management, test backlog), **CRO Bot** (test design, variant copy for landing pages/forms), **Outbound Bot** (lead enrichment, outreach in brand voice, meeting booking). Bots hand off work: Content finishes article → PR pitches it → Outbound reuses in outreach. Setup: 1) Load Company Brain, 2) Create one bot per vertical, 3) Configure harness (model, skills, tools, memory), 4) Start with one job per bot and iterate.

## Key Takeaways

- **Bot Mode = named specialist agents** — Each bot: role, model, memory, skills, tools, pfp
- **Inter-bot communication** — Bots send work to each other (handoff workflows)
- **Company Brain = shared context** — Centralized knowledge: campaigns, voice, strategy, examples
- **Research Bot = external eyes** — Scrapes competitors, trends, channels continuously
- **7 marketing verticals covered** — Research, SEO, Content, PR, Paid, CRO, Outbound
- **Model tiering** — Cheap/fast models for throughput, stronger models for review
- **Skill specialization** — Each bot gets only the skills/tools its vertical needs
- **Memory per bot** — Remembers context across jobs within its vertical
- **Reusable specialists** — Build once, use across multiple campaigns
- **Context is the moat** — Past campaigns, strategy, taste, "what good looks like"

## Summary

Chris (@everestchris6) shared a thread about building an OpenClaw bot that scraped 1,000+ leads for cold outreach. The bot's strategy: find businesses with bad websites, flag them as "hot leads," and automate the outreach process. The system identifies prospects by scanning for poor web design/UX, then generates personalized outreach. The thread ended with a call-to-action to get the full system setup for free. Key insight: combining web scraping with AI-powered website auditing creates a powerful lead generation pipeline — the bot does prospecting, scoring, and initial outreach automatically. This is particularly relevant for freelance web developers and agencies looking to scale client acquisition without manual prospecting.

## Key Takeaways

- OpenClaw bot scraped 1,000+ leads by scanning for businesses with bad websites
- Automated lead scoring: bad website = hot lead (they need help)
- The pipeline combines scraping + AI auditing + personalized outreach
- Cold outreach at scale requires automation — manual prospecting doesn't scale
- The system can potentially build prospects new sites and send them automatically
- Free system shared via thread — worth investigating the actual setup

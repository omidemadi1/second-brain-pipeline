## Summary

A comprehensive video guide on defeating "AI slop" in web design — the generic, recognizable look that AI tools produce by default. The presenter outlines a 3-step workflow for injecting personal taste into AI-assisted design work.

### Step 1: Cultivate Taste

- Build a **design inspiration library** from Dribbble, Pinterest, and Twitter
- Screenshot and save designs you like — this becomes your taste reference
- Create a simple web app to organize screenshots by design type with vocabulary/keywords
- Expose yourself to high-level design work to understand what you actually like

### Step 2: Bring Taste to AI

- Use **MCP tools** and reference images to guide AI design output
- The presenter uses a custom MCP called **Impeccable/Taste Skill** that lets you feed inspiration images to Claude
- Reference images + specific prompts > vague instructions like "make it premium"
- Use **Tweaks Bar** for visual iteration without regenerating entire pages

### Step 3: Iterate and Tweak

- Use visual tweaking tools to adjust fonts, colors, spacing, and layout in real-time
- Iterate visually rather than playing the "prompt lottery"
- Show AI more references of things you like until the output matches your taste
- The workflow is flexible — none of it needs to be followed prescriptively

**Key insight:** AI has no taste. It produces average, regression-to-the-mean output. The solution isn't better prompts — it's injecting your curated taste into the process.

## Key Takeaways

- AI design tools produce generic output because they have no taste — the solution is human curation
- Build a design inspiration library from Dribbble, Pinterest, and Twitter before starting any AI design work
- MCP tools like Impeccable let you feed reference images to Claude for taste-guided generation
- Visual tweaking (fonts, colors, spacing) is faster than regenerating entire pages
- The workflow is: curate → reference → generate → tweak → repeat
- AI slop evolves — as models improve, "generic" just changes shape, so taste injection remains essential

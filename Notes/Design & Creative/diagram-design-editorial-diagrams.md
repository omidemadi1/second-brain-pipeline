## Summary

Diagram Design by Cathryn Lavery provides 38 editorial diagram types as self-contained HTML + SVG files — zero dependencies, no shadows, "no Mermaid slop." Designed specifically for AI coding agents (Claude Code, Codex, Pi) to generate professional diagrams programmatically. The repo has 24,321 stars, indicating massive adoption. Each diagram type is a standalone, copy-pasteable component covering categories like architecture, flowcharts, sequences, timelines, comparisons, hierarchies, networks, and more. Live demo at cathrynlavery.github.io/diagram-design/.

## Key Takeaways

- **Agent-native**: Built for LLMs to generate — clean, predictable SVG output without Mermaid's rendering quirks
- **38 diagram types**: Comprehensive coverage — architecture, flow, sequence, timeline, comparison, hierarchy, network, process, data, org charts, etc.
- **Self-contained HTML+SVG**: Drop into any webpage, no build step, no JS runtime, no CSS dependencies
- **Design quality**: Editorial style — clean, professional, consistent; "no shadows" = flat, modern aesthetic
- **Agent skills integration**: Tagged for agent-skills, claude-code, codex — ready for tool-use workflows
- **Mermaid/Draw.io alternative**: Avoids Mermaid's version conflicts, rendering inconsistencies, limited styling

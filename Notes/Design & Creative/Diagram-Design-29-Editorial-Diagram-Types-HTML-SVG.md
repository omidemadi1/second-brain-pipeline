## Summary

Diagram Design is a skill for Claude Code and Codex that generates 29 types of editorial-quality diagrams as clean, editable HTML+SVG — no Mermaid slop, no Figma needed. It automatically reads your site's brand colors and applies them. Diagram types include architecture, flowcharts, sequences, entity-relationship, timelines, mind maps, and more. 19.5K stars on GitHub. Output is self-contained HTML files with embedded SVG that can be edited in any browser or code editor.

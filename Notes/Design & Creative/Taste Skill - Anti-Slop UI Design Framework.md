## Summary

Taste Skill is an open-source guide file (73k+ stars) that teaches AI coding tools to produce better, less cliché UI designs. It explicitly bans purple gradients, glass cards, and other overused patterns. Covers fonts, spacing, colors, animations, and brand alignment. Works with Cursor, Claude Code, Codex, Windsurf, v0, Lovable, and any tool supporting SKILL.md files. Install via `npx skills add`. Version 2 reads the brief, infers design direction, and ships interfaces that don't look templated. Includes 13 specialized skills covering visual styles (minimalist, brutalist, soft), execution quality, image generation, and brand kits.

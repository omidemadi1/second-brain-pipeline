# Diagram Design — Editorial SVG/HTML Diagram Skill for AI Agents

## Summary

Diagram Design is an open-source AI skill (31k+ GitHub stars) that teaches AI coding assistants — Claude Code, Codex, Factory Droid, and Pi — to generate high-quality editorial diagrams as self-contained HTML files with inline SVG and CSS. It offers 38+ diagram types including architecture diagrams, flowcharts, sequence diagrams, trust boundaries, and more. The key differentiator: no Mermaid dependency, no shadows, no visual slop. Each diagram follows an opinionated editorial design system that produces clean, publication-quality visuals.

The skill supports automatic brand matching — give it your website URL and it reads your existing design to match all diagrams to your brand colors and style. It also supports theme switching (light/dark/full-editorial), optional motion for ordered explanations, and can redraw existing .drawio or Mermaid sources at a chosen format, size, and detail level. Semantic patterns describe behavior separately from layout, allowing reuse of diagram types without expanding the type count.

## Key Takeaways

- **38+ editorial diagram types** covering architecture, flows, sequences, data models, trust boundaries, policy traces, and more
- **Self-contained HTML+SVG output** — no external dependencies, no Mermaid runtime needed
- **Brand matching**: reads your website CSS and matches diagram styles to your existing design system automatically
- **Theme support**: light, dark, and full-editorial tabs for flexible presentation
- **Semantic patterns**: separate behavior from layout, enabling reuse and flexibility
- **Optional motion**: accessible animations for ordered step-by-step explanations
- **Draw.io/Mermaid import**: redraws existing diagrams at a chosen format and detail level
- **Works with multiple AI agents**: Claude Code, Codex CLI, Factory Droid, Pi — plugin architecture for extensibility
- **MIT licensed**, actively maintained (135+ commits), trending on GitHub

# LottieFiles Motion Design Skill — Teaching AI Agents Professional Motion Design

## Summary

LottieFiles has released an open-source **Motion Design Skill** for AI agents that teaches them to think like professional motion designers before writing animation code. Instead of just generating a few lines of animation code, this skill trains agents to reason about timing, easing, choreography, emotional intent, and Disney's 12 principles of animation adapted for UI.

## Key Takeaways

- **Pre-coding decision framework**: Agents learn to plan animation decisions BEFORE writing code — considering timing, easing curves, multi-element choreography, and emotional goals.
- **Disney principles for UI**: The classic 12 principles of animation (squash & stretch, anticipation, follow-through, etc.) adapted specifically for user interface motion design.
- **GitHub repo**: github.com/LottieFiles/motion-design-skill — available for integration into any AI agent framework.
- **Covers**: Timing, Easing (acceleration/deceleration), Choreography (coordinating multiple moving elements), Emotional intent of motion.

## Why It Matters

Most AI-generated animations are functional but lifeless. This skill bridges the gap between "code that moves" and "motion that feels professional." For anyone building AI-assisted design tools or web animations, this provides a reusable knowledge base that agents can reference.

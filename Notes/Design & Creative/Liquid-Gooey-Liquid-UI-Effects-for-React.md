# Liquid Gooey - Liquid UI Effects for React

## Summary

Liquid Gooey (gooey.jakubantalik.com) is a React library that provides liquid/gooey/jelly UI effects for web interfaces. Two core effects:

- **Morph**: Merges, reshapes, and dissolves touching UI pieces — elements appear to flow into each other like liquid when they get close.
- **Move**: Trails a moving element as liquid rubber — elements stretch and deform as they move, creating an organic, viscous feel.

Key characteristics:
- Cross-browser support including Safari
- React-based (npm installable)
- Designed for modern web interfaces that want organic, fluid feel
- Not just visual gimmick — adds tactile quality to UI interactions
- Live demo available at gooey.jakubantalik.com

The gooey effect is created using CSS filters (blur + contrast trick) combined with JavaScript for dynamic positioning. This technique has been popular in creative web design but this library makes it production-ready with proper React integration.

## Key Takeaways

- React library for liquid/gooey/jelly UI effects
- Two effects: Morph (merge/dissolve) and Move (rubber trail)
- Cross-browser including Safari
- Live demo at gooey.jakubantalik.com
- Useful for adding organic, tactile feel to web interfaces
- Can be applied to menus, buttons, navigation, cards, etc.

## Summary

Gowtham R (@gowtham_techie) shares a comprehensive carousel on web animation fundamentals, emphasizing that animation is about making users *feel* movement, not just making things move. The post covers key techniques: ScrollTrigger and Pin animations, Parallax effects, Horizontal Scroll, Scroll Progress indicators, and Scroll-Linked animations. It recommends four core tools: GSAP (industry standard for complex animations), Framer Motion (React-friendly declarative animations), Lenis (smooth scrolling), and Three.js (3D/WebGL). The core philosophy: animate with purpose, not just because you can.

## Key Takeaways

- **Philosophy first**: Animation serves UX — guides attention, provides feedback, creates delight, tells stories
- **GSAP**: Best for complex timelines, scroll-linked animations, cross-browser consistency; ScrollTrigger plugin is essential
- **Framer Motion**: Ideal for React apps; declarative API, layout animations, shared layout transitions
- **Lenis**: Lightweight smooth scroll library; pairs well with GSAP ScrollTrigger
- **Three.js**: For 3D/WebGL experiences; steep learning curve but unmatched for immersive visuals
- **Technique toolkit**: ScrollTrigger (pin, scrub), Parallax (depth), Horizontal Scroll (narrative), Scroll Progress (orientation), Scroll-Linked (interactive)

## My Notes

- Save this carousel as a reference for the next frontend project requiring polished animations
- GSAP + Lenis is a common modern stack for scroll-heavy sites
- Framer Motion has improved significantly for gesture/animation handling in React 18+
- Three.js + GSAP can create scroll-driven 3D narratives (e.g., product showcases)
- Performance consideration: animate transforms/opacity only; avoid layout thrashing
- Accessibility: respect `prefers-reduced-motion`, provide skip options

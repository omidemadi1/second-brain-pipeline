## Summary

Circle Loaders is a collection of 24 monochrome, circular loading animations by Dominika Kissi. All animations are built as pure SVG + CSS with zero dependencies, making them easy to embed in any web project or app.

Key features:
- **24 unique spinner designs** — each clipped to a disc with hairline strokes
- **Pure SVG + CSS** — no JavaScript dependencies, embed with a single `<svg>` tag
- **Reduced-motion aware** — respects `prefers-reduced-motion` media query for accessibility
- **Monochrome** — clean single-color design that fits any color scheme
- **Free to use** — standalone animated SVGs, copy-paste ready
- Perfect for loading states, skeleton screens, and async operation indicators in web and mobile apps

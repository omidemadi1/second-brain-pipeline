## Summary

Official Taste Skill site. v2 (experimental) is the new default: reads the brief, infers design direction, ships interfaces that don't look templated. 13 specialized skills available: design-taste-frontend (v2), v1 legacy, gpt-tasteskill, image-to-code, redesign, soft, output, minimalist, brutalist, stitch, imagegen (web/mobile), and brandkit. Structure covers brief inference, design-system mapping (Material, Fluent, Carbon, Polaris, etc.), dark mode protocol, redesign protocol, block library schema, and a hard pre-flight check. Install: `npx skills add Leonxlnx/taste-skill`.

## Key Takeaways

- v2 experimental: brief inference + non-templated output
- 13 skills covering visual styles, execution, image generation, brand kits
- Design system mapping: when to use Material vs Fluent vs Carbon etc.
- Dark mode protocol: dual-mode by default
- Hard pre-flight check before shipping
- Install: npx skills add Leonxlnx/taste-skill

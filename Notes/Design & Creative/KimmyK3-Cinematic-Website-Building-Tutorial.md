## Summary

**What:** A comprehensive tutorial on creating cinematic, scroll-driven websites using KimmyK3 (Moonshot's frontier model) that combine AI-generated video with interactive web experiences.

**Key techniques covered:**
- Generating background video assets using AI (concepts, scenes, animations)
- Frame interpolation for smooth scroll-based video playback
- Binding video progress to scroll position for interactive exploration
- Auto-play tour-based experiences for guided navigation
- Wrapping everything in KimmyK3's code generation for clean frontend output

**Use case:** Web designers and creators who want to build immersive, cinematic websites with scroll-driven animations using AI tools.

> This workflow makes high-end interactive experiences accessible to non-specialists.

## Key Takeaways

- The core technique: bind video frames to scroll position for interactive exploration
- AI handles concept generation, video creation, and frontend code
- KimmyK3 competes with GPT-5.6 and other frontier models for code generation
- Frame interpolation is critical for smooth, non-chunky scroll experiences
- Free templates and prompts available in the creator's Maker Zero community
- The approach works with multiple AI models (Claude, GPT, Kimmy)

## My Notes

- The scroll-to-video binding is a powerful UX pattern
- Could be adapted for product showcases, storytelling, or portfolio sites
- Worth exploring KimmyK3 as an alternative to other AI code generators

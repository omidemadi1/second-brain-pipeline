# Handy — Offline Speech-to-Text Desktop App

## Summary
Handy (github.com/cjpais/Handy) is a free, open-source, cross-platform desktop application that provides simple, privacy-focused speech-to-text transcription that works completely offline. The note (from apt_hq) praises it as having excellent Persian support — "really unrivaled" — and shows a global-shortcut workflow: hold the shortcut, speak, release, and it types for you. Web research confirms: Handy is extensible, works on Linux/macOS/Windows, and is positioned as a painless, free STT alternative to cloud services like Whisper APIs for users who want everything local.

## Key Takeaways
- 100% offline — no data leaves the machine, privacy-first by design.
- Strong Persian (Farsi) dictation support, which is a differentiator vs many STT tools.
- Global shortcut workflow: hold → speak → release → text is typed.
- Cross-platform: Linux, macOS, Windows.
- Free and open source; extensible architecture.

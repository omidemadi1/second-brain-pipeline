## Summary

Tuby (تیوبی) is a Chrome extension that uses AI to generate accurate Persian (Farsi) subtitles for YouTube videos. It works directly within the YouTube interface — click the Tuby icon on any video to get translated subtitles instantly.

**Key features:**
- AI-generated Persian subtitles for YouTube videos
- One-click activation within YouTube's native interface
- Customizable subtitle appearance (size, style, position)
- Free to install and use

**How it works:**
1. Install the Chrome extension
2. Open any YouTube video — the Tuby icon appears
3. Click the icon to generate and display Persian subtitles

## Key Takeaways

- Provides AI-generated Persian subtitles for any YouTube video
- Runs entirely within YouTube — no separate app needed
- Free Chrome extension with customizable display settings
- Useful for Persian speakers consuming English-language content

## My Notes

A practical tool for Persian-speaking users who want to understand English YouTube content better. The AI-powered subtitle generation means it works on any video, not just those with existing subtitles. The customization options (size, position, style) are a nice touch for accessibility.

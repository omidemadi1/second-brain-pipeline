## Summary

An educational Instagram post about AI agent privacy and security. The core message: when you use AI tools like v0, Cursor, Lovable, or any web-based AI tool, if you're not logged out and have API keys visible, your data may be at risk. The post warns that what you think is safe inside your workspace might actually be exposed through AI tool integrations. It emphasizes the importance of understanding how AI agents access and handle your data, and the need for proper security practices when using AI-powered development tools.

## Key Takeaways

- **AI tools can expose secrets**: If API keys are visible in your workspace, AI agents may access them.
- **Log out when not in use**: Reduces the attack surface for session-based exploits.
- **Understand tool permissions**: Know what data your AI coding tools can access.
- **Defense in depth**: Don't rely solely on AI tool providers for data security.
- **Common risk**: Developers often store API keys in environment variables or config files that AI tools can read.

## My Notes

Good general reminder. Relevant for any developer using AI tools — always audit what access your AI agents have to sensitive files and keys.

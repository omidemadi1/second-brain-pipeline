## Summary
AI-driven penetration testing tool that detects 45+ vulnerability types including SQLi, XSS, SSRF, XXE, SSTI, RCE, deserialization, JWT, OAuth flaws and more. Uses OpenAI as backend. Orchestrates multiple AI providers (OpenAI, Claude, Grok, Gemini, OLLAMA, Groq, Mistral, OpenRouter, LiteLLM, LM Studio) for intelligent payload generation.

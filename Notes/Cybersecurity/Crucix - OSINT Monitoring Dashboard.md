# Crucix - OSINT Monitoring Dashboard

**Source:** [https://github.com/calesthio/Crucix](https://github.com/calesthio/Crucix)

## Summary

Open-source real-time geopolitical/security monitoring dashboard (10.7k stars). Tracks 26 live sources including satellite fires, flights, ships, conflict zones, crypto, and social sentiment with Telegram/Discord alerts.

## Key Takeaways

- 10,708 stars on GitHub — very popular OSINT tool
- 26 live data sources updated every 15 minutes
- Satellite fire tracking, flight/ship tracking, conflict zone monitoring
- Crypto/markets and Telegram social sentiment analysis
- Alerts via Telegram and Discord — no cloud server needed
- Live demo available at crucix.live

## Summary
Cybersecurity practitioner **@cyberphobiatv** shared a curated list of **5 free, open-source AI security tools** worth knowing in 2026. These tools cover the emerging AI red-teaming and security testing landscape: **PentAGI** (autonomous AI security testing, self-hosted), **PentestGPT** (AI assistant for security testing and learning), **Garak** by NVIDIA (jailbreak and prompt injection testing for your own AI systems), **PyRIT** by Microsoft (multi-turn AI red teaming and risk assessment), and **Promptfoo** (AI red teaming integrated into CI/CD pipelines). All tools are authorized for use only on systems you own or have explicit permission to test. The post emphasizes a layered approach — combining tools for comprehensive coverage rather than relying on a single solution.

## Key Takeaways
- **PentAGI**: Autonomous, self-hosted AI pentesting — runs locally, no data leaves your environment.
- **PentestGPT**: Interactive AI assistant that guides security testing workflows and teaches methodology.
- **Garak (NVIDIA)**: Specialized for LLM vulnerability scanning — prompt injection, jailbreaks, data leakage. CLI and library interfaces.
- **PyRIT (Microsoft)**: Framework for multi-turn red teaming, scoring, and risk assessment — supports custom attack strategies and converters.
- **Promptfoo**: Config-driven evaluation suite that plugs into CI/CD — catch regressions in prompt robustness on every deploy.
- **Layered defense**: The community recommends using Garak/PyRIT for pre-deployment stress tests + Promptfoo for continuous CI/CD guardrails.

## My Notes
- This aligns with the "shift-left" trend in AI security — moving red teaming into dev workflows, not just post-deployment audits.
- Garak is the go-to for quick scans; Promptfoo for regression prevention; PyRIT for deep, campaign-style assessments.
- All 5 are MIT/Apache-2 licensed — commercially friendly.

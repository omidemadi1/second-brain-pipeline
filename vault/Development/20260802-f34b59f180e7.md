# Sooda - Pricing Calculator

## Summary
Free pricing calculator tool for businesses. Calculates profit, selling price, discounts, and profit margins.

## Features
- Profit calculation
- Selling price computation
- Discount calculations
- Profit margin analysis
- Simple and fast UI
- Offline-first PWA
- Bilingual (EN/FA)

## Technical Details
- TypeScript
- Zero server dependencies
- Liquid-glass design

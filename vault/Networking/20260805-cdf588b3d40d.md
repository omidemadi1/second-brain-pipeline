# Stackyard - Homelab Dashboard

## Summary
Self-hosted homelab dashboard with calm, live activity badges from any API. Single container, zero dependencies.

## Features
- System status monitoring
- Disk health tracking
- Backup status
- Network speed tests
- GitHub integration
- Library tracking
- Service monitoring
- Add any API data as widget/badge without coding

## Technical Details
- Single container deployment
- Zero dependencies
- PWA support

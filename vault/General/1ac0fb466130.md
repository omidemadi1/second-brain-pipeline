### Key Insight: Graph Memory for Agents

Giving agents graph memory (storing people, events, decisions, and their relationships) is one of the most interesting ideas for better agents — but the **cost problem** is significant.

Each new message, meeting, file, or event requires extraction of entities and relations at scale. When repeated, the memory system that was supposed to make the agent efficient becomes the most expensive part.

**Crucial distinction:** Writing to memory vs reasoning over memory are two very different tasks and shouldn't use the same settings.

- **Extraction** (writing): cheap, repetitive, mechanical — don't need max reasoning power
- **Retrieval + reasoning** (reading): complex, multi-hop, contradiction detection — need deeper reasoning

Smart effort allocation dramatically reduces agent memory cost without sacrificing quality.

Relevant for: long-term agents, graph memory, multi-agent systems.

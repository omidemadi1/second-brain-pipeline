# Simple AI Agent Memory System

## Summary
Four markdown files and zero databases - the simplest AI agent memory system that actually works.

## The System

### 1. One File Per Domain, Never Per Date
- Create separate files: people.md, companies.md, deals.md, tasks.md
- Each file owns one topic
- Avoid chronological brain dumps (unsearchable after 2 weeks)
- Domain separation = fast lookups

### 2. MEMORY.md Index
- One file listing every memory file with one-line description
- Agent loads index first, then specific files on demand
- Predictable context window usage

### 3. Cache Files with Freshness Headers
- Files mirroring external sources are caches, not sources of truth
- Mark with last_sync timestamp
- Agent announces data freshness before analysis
- Prevents wrong-but-confident outputs

### 4. Flat Markdown, Not Databases
- Readable, searchable, git-trackable
- No embedding pipeline or retrieval infrastructure
- Skip abstraction layers
- Simplest architecture that works

## Implementation
- Set up in 20 minutes
- Version-controlled from day one

### Taste Skill — Anti-Cliché UI Design for AI

A set of instructions for AI coding tools that helps create more professional, coherent, and less cliché UI designs. **Not a framework/library** — a guide file that AI reads before designing and coding.

**What it decides:**
- Appropriate fonts and compositions
- Spacing and color choices
- Animation usage and placement
- Brand identity alignment
- Avoiding repetitive patterns (no more purple gradients, glass cards, demo dashboards!)

Works with: Cursor, Claude Code, Codex, Windsurf, v0, and other tools.

**Install:**
```bash
npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"
```

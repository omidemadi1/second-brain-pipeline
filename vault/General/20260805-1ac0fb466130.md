# Graph Memory for AI Agents - Cost Considerations

## Summary
Key insight about AI agent memory systems: "Writing to memory" and "thinking about memory" are two different operations and shouldn't use the same effort level.

## Key Points
- Graph memory stores people, events, decisions, and relationships
- Cost becomes a major concern at scale when extracting entities from every new message/file/event
- Extraction should be cheap and high-volume
- Retrieval and reasoning should be powerful and targeted
- Smart effort allocation reduces costs without sacrificing quality

## Applications
- Long-term agents
- Graph memory systems
- Multi-agent systems

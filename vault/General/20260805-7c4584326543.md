# Taste Skill - AI UI Design Guidelines

## Summary
A skill/guideline file for AI coding tools that helps create more professional, cohesive, and less clichéd user interfaces.

## Problem It Solves
- AI-generated sites often have the same purple gradient, three cards side by side, big text, generic look
- Taste Skill acts as a design art director/critic for coding agents

## What It Does
- Guides font and composition choices
- Advises on spacing and color selection
- Controls animation usage and placement
- Ensures design aligns with brand identity
- Prevents repetitive, unjustified patterns

## Installation
```bash
npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"
```

## Compatibility
- Cursor, Claude Code, Codex, Windsurf, v0, and other tools
- Framework-agnostic

## AI & Machine Learning

### You Cannot Filter Your Way Out of Prompt Injection

**By:** Eugen Ullrich (@eullrich) — GEO & AI Visibility Strategist

**Key points:**
- Filters and system prompts don't stop prompt injection — **architecture does**
- The **Lethal Trifecta:** untrusted text + data access + tool use = prompt injection
- Simon Willison's **Dual-LLM pattern**
- Google DeepMind's **CaMeL system**
- **Six design patterns** from a 2025 paper

**Two classic attack shapes:**
1. **Confused deputy:** High-privileged program tricked into abusing authority
2. **Data exfiltration:** Unauthorized removal of data via outbound HTTP calls

**Why "just tell the model to ignore it" fails:**
- System prompt approach is finite against infinite attack variations
- Model is non-deterministic — "usually obeys" is not a security property
- Classifiers: in app security, 99% is a failing grade

Working implementation on three models that never see each other, with deterministic checks.

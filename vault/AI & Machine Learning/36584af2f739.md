# Taste Skill — Anti-Slop Frontend Framework

## Summary
Guide file for AI coding tools that improves UI design quality. Teaches AI to avoid cliché designs (purple gradients, glass cards). Covers fonts, spacing, colors, animations, brand alignment. Works with Cursor, Claude Code, Codex, Windsurf, v0.

## Install
```bash
npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"
```

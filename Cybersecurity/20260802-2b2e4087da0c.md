# HyperDbg - Hardware & Software Debugging Infrastructure

## Summary
State-of-the-art open-source debugging tool using Intel VT-x/EPT for user/kernel mode debugging.

## Features
- Stealth hooking
- Anti-anti-debug capabilities
- Precise code execution tracing
- Hardware-level debugging via virtualization

## Use Cases
- Reverse engineering
- Malware analysis
- Kernel development
- Security research

## Technical Details
- Uses Intel VT-x/EPT technology
- Supports both user and kernel mode
- Native debugging tools
